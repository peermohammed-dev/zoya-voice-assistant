# 🤖 ZOYA - AI Virtual Voice Assistant

ZOYA is a Python-based AI Voice Assistant that enables hands-free interaction with your computer using voice commands. It supports both GUI-based interaction and background voice control.

---

## 🚀 Features

### 🎤 Voice Recognition
- Wake word activation ("Hey Zoya")
- Continuous listening and command execution
- Speech-to-text using Google Speech API

### 🔊 Text-to-Speech
- Natural voice responses using pyttsx3
- Custom voice and speed control

### 🖥️ GUI Interface
- Interactive graphical interface (Tkinter)
- Real-time chat display
- Status indicators (Listening, Processing, etc.)

### ⚙️ System Control
- Open/close applications (Notepad, Calculator, etc.)
- Volume & brightness control
- Shutdown, restart, sleep system
- Screenshot capture

### 🌐 Web & Search
- Open websites (YouTube, Google, etc.)
- Google search via voice
- Wikipedia integration

### ⌨️ Productivity Tools
- Voice typing (single & continuous)
- File navigation (Downloads, Desktop, etc.)
- Select, copy, paste actions

### 🤖 AI Capabilities (Optional)
- Intent classification using Keras model
- Smart chatbot responses

---

## 🛠️ Tech Stack

- Python
- SpeechRecognition
- pyttsx3
- Tkinter (GUI)
- PyAutoGUI
- NumPy
- Keras / TensorFlow (optional ML)
